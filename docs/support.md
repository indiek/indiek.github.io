# Support IndieK

IndieK is free and open-source software. If it's useful to you, you can
support its development:

<p>
<a href="https://github.com/sponsors/indiek"><img src="/assets/img/badge-github-sponsors.svg" alt="Sponsor IndieK on GitHub Sponsors" width="150" height="28"></a>
<a href="https://ko-fi.com/indiek_sponsoring"><img src="/assets/img/badge-kofi.svg" alt="Support IndieK on Ko-fi" width="150" height="28"></a>
</p>

- [GitHub Sponsors](https://github.com/sponsors/indiek), for developers with
  a GitHub account (0% platform fees)
- [Ko-fi](https://ko-fi.com/indiek_sponsoring), one-time or monthly, no
  account needed

All donations strictly fund the open-source core of IndieK and its public
infrastructure.
