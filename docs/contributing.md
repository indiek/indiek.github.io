---

Contributions are welcome. Please open issues or pull requests to improve the specification, examples, or tooling. Keep changes small and focused. Use SPDX identifiers for licenses and follow existing schema conventions.

Suggested workflow:

1. Open an issue describing the change.
2. Submit a PR with updates to `docs/` and example archives in `examples/`.
3. Maintain semantic versioning for the spec.
